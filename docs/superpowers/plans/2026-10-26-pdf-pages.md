# Full PDF evidence implementation plan

> **For agentic workers:** Use superpowers:executing-plans.

**Goal:** Preserve every physical PDF page with revision-sensitive identities and retrieve exact page citations from scoped Memory.
**Architecture:** Parse full bytes atomically with the pinned pypdf, capture page Source values through the existing registry, and search using only public scoped Memory APIs. Rank lexical candidates from actual stored text, without reading labels or answers.
**Tech Stack:** Python 3.12, pypdf, hashlib, Pydantic, native Memory APIs.
**Spec:** `competition/challenges/source-03-pdf-retrieval/instruction.md`

## Global Constraints

All physical pages, including blank pages; full-file lowercase SHA-256; readable empty-password permissions; invalid/unreadable PDF raises ValueError atomically. No OCR, models, network, additional dependencies or access to judge assets. Stable captured page identity bounded to 256 characters. Exact three-key projection metadata. Return at most limit distinct physical-page MemoryCitations.

## Review Focus

- Valid blank pages and permission-encrypted PDFs do not disappear.
- Long or delimiter-containing document IDs remain distinct and bounded.
- Failed later-page extraction does not return partial pages.
- Duplicate hit identities or multiple Memory records for one page do not duplicate citations.
- Full 1151-page/24-question quality thresholds cannot be inferred from the public five-question citation check.
