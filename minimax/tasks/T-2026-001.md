## GOAL | 目标

在 `sample_project/jmespath`（上游 jmespath.py v1.1.0，MIT）里实现内建谓词函数
`matches(subject, pattern)`，让 JSON 查询可以用正则做筛选条件，
例如 `people[?matches(name, '^a')].name`。

实现必须严格符合规格 `SPEC-JP-FN-001` 的 R1–R6 与不变行为 B1–B3。

## KEEP | 必须保持的行为

- jmespath 现有 23 个内建函数的签名、返回值与异常行为完全不变
- lexer.py、parser.py、visitor.py、ast.py 的行为不变
- tests/compliance/ 下全部 JMESPath 合规用例仍然通过
- 现有的 `pytest tests/` 基线（991 passed, 1 skipped）不得退化为失败

## ACCEPT | 验收命令

- python -m pytest tests/test_matches.py -q
- python -m pytest tests/ -q

## NOTE | 目标测试

新增测试文件 `tests/test_matches.py` 是本次任务的目标测试：
