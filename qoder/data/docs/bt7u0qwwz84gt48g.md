| 项目 | 说明 |
| --- | --- |
| 项目 | 魔搭社区 |
| 题目 | 上传并分享自己的 Skill |
| 任务 | 将一个自己的 Skill 上传到魔搭社区 |
| 提交产物 | 该 Skill 在魔搭社区的网址或编号 |
| 总分 | 20 |

## 一、题目背景
本题鼓励参赛者将自己的 Skill 分享到魔搭社区，完成从上传作品到提交参赛信息的实践。

## 二、题目内容
### 2.1 上传自己的 Skill
1. 注册并登录魔搭社区账号。
2. 准备一个自己编写的 Skill，按照魔搭社区的上传流程完成上传。
3. 上传成功后，确认能够查看该 Skill 的内容，并获取其网址或编号。

建议为 Skill 填写清晰的名称和功能说明，并附上简短的使用示例，方便其他用户了解和使用。

### 2.2 获取提交信息
以下两种信息**任选其一**：

+ **Skill 网址**：复制该 Skill 在魔搭社区的完整页面链接。
+ **Skill 编号**：复制魔搭社区中该 Skill 对应的编号，保留完整内容。

提交的信息应能准确定位到自己上传的 Skill，不要填写个人主页、账号 ID 或仅填写 Skill 名称。

## 三、提交方式
1. 登录大赛测试平台，进入**魔搭社区赛题**的提交入口。
2. 将 Skill 的**网址或编号**填写到对应字段并提交。
3. 核对提交信息，确认其对应的是自己已成功上传的 Skill。

完整流程为：**准备自己的 Skill → 上传到魔搭社区 → 获取网址或编号 → 提交到测试平台**。

## 四、提交前检查
| 检查项 | 要求 |
| --- | --- |
| Skill 上传 | 已将自己的 Skill 成功上传到魔搭社区 |
| 信息有效 | 提供的网址或编号能够准确定位到该 Skill，并可查看上传内容 |
| 平台提交 | 已在测试平台的魔搭社区赛题入口提交网址或编号 |
