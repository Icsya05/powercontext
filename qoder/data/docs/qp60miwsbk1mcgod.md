## 一、题目背景
“附近有什么值得去的地方？”是一个常见的出行问题。本题要求基于高德开放平台，编写一个轻量的周边探索 Skill，让用户用一句话找到合适的地点，并知道如何到达。

例如：“我在杭州某地铁站，想找一家咖啡馆，步行不超过 15 分钟，推荐最多 3 家，优先近一点的。”

助手需要查询真实地点和步行路线，给出简洁、可信的推荐。完成一次“提出需求 → 查询高德 → 返回推荐”即可。

## 二、题目内容
### 2.1 编写周边探索 Skill
在 Skill 文件中描述任务流程，引导 Agent 使用高德 MCP Server 的以下两项能力：

1. **地点搜索**：根据起点和用户需求，查询附近的咖啡馆、餐厅、公园等地点。
2. **步行路线规划**：查询从起点到候选地点的步行距离和预计耗时。

评测时由平台统一提供 Agent 运行环境、模型和高德工具配置，加载参赛者提交的 Skill 执行任务。参赛者只需在文件中写清楚需求理解、工具调用、地点筛选和回答生成的步骤。

长期记忆、多轮反馈、跨城市经验迁移，以及 PowerMem、seekdb 接入均不作为本题必做项。

### 2.2 根据需求推荐地点
输入包含城市、起点和自然语言需求。评测时会提供明确的起点坐标，参赛者不必实现设备定位。

助手需要：

1. 理解地点类型、步行时间上限、推荐数量等要求。
2. 从高德查询结果中筛选候选地点，查询步行路线，返回最多 3 个符合条件的推荐。
3. 为每个地点提供名称、地址、预计步行距离与时间，以及一句推荐理由。

各地点都是从同一起点出发的独立备选，不需要串成多站行程。步行时间应来自路线查询，不能用直线距离替代。

不足指定数量时可以少推荐，并说明原因；查询失败或没有找到符合条件的结果时，应如实说明，可建议用户放宽条件。对安静程度、排队情况、营业状态等缺少依据的信息，应标注“未核实”，不能编造。

### 2.3 明确回答要求
Skill 应指导 Agent 用列表或表格呈现推荐结果，包含地点名称、地址、预计步行距离与时间、推荐理由；遇到结果不足、信息未核实或查询失败时，补充简短说明。

高德工具调用记录由评测平台自动采集，用于核对地点与路线。参赛者无需额外导出 JSON、上传日志或编写测试脚本。

## 三、验收与评测
### 3.1 评测场景
平台加载提交的 Skill，使用统一的单轮任务评测其实际效果，不进行源码测试。用例主要覆盖：

| 场景 | 示例与检查重点 |
| --- | --- |
| 普通推荐 | 推荐起点附近最多 3 家咖啡馆，地点真实且类型符合需求 |
| 时间限制 | 只推荐步行 15 分钟内可达的地点，不将超时地点列为符合条件的推荐 |
| 偏好排序 | “优先近一点”，推荐顺序和解释应与路线数据一致 |
| 结果不足或查询异常 | 如实说明查询范围内未找到足够结果，或说明服务异常，不编造地点和路线 |

### 3.2 评分方式
采用**规则校验 + AI 评审**，按以下权重综合评价：

| 维度 | 权重 | 评测方法 |
| --- | --- | --- |
| 数据真实性 | 40% | 平台依据工具调用记录，核对回答中的地点、位置和路线数据是否与高德返回结果一致 |
| 需求满足 | 30% | 平台检查数量、步行时间等明确条件；AI 结合校验结果判断是否回应用户需求 |
| 推荐合理性 | 20% | AI 判断筛选、排序和推荐理由是否有数据依据，是否合理处理无结果或信息缺失 |
| 表达清晰度 | 10% | AI 判断回答是否简洁、易懂，能否帮助用户做出选择 |

AI 评审同时读取**用户需求、高德查询结果、平台校验结果和助手回答**，不只看最终文案。未经数据支持的描述不能作为加分依据；明确违反的硬性条件不能由 AI 改判为满足。无结果用例依据是否正确处理该情况评分，不因推荐数量为零直接扣分。

评测使用统一用例、执行模型、评审模型版本和评分提示词，输出各维度得分及简短理由。高德调用记录由评测端自动采集，并保存数据快照供复测使用；参赛回答仅作为待评内容，不作为评审指令。评测端的公共服务故障应重试，不直接计为参赛方案失败。

## 四、提交材料
仅需向提测平台上传一个 **Skill 文件（SKILL.md）**，文件中写明：

1. Skill 的名称、用途和适用场景。
2. 使用高德工具查询地点、获取步行路线、筛选推荐的步骤。
3. 回答格式，以及结果不足、信息缺失或工具调用失败时的处理方式。

无需提交源码、代码仓库、独立应用、测试报告或演示视频。运行环境和高德 API Key 由评测平台配置，不要在 Skill 文件中填写密钥。

参考资料：[高德 MCP Server](https://developer.amap.com/api/mcp-server/summary)。
