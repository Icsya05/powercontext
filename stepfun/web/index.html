端侧知识库

embedding 在你的浏览器里算，检索由 seekdb 在数据库内完成

正在检测推理后端…

1 · 端侧模型

模型文件来自 Hugging Face 公开仓库 …（apache-2.0）。 首次加载会从本地 /models/ 读取（由 scripts/fetch-model.mjs 预置）， 之后走浏览器缓存 —— 全程不需要访问外网。

2 · 导入语料

粘贴文本，一段一行。浏览器本地切块并向量化，然后写入 seekdb （向量列 VECTOR(384) + ik 全文索引 + VSAG HNSW 向量索引）。

3 · 混合检索

查询向量同样在浏览器本地生成。服务端只做一次 hybridSearch() 调用，全文腿与向量腿的融合在 seekdb 内完成。

4 · 数据与证据

「查看表结构」和「导出行级数据」直连 seekdb，用来证明向量、原文与元数据确实存在数据库里。 


      


      

        
5 · 合规自检

        
    
          
  • 服务端进程里没有任何模型、没有任何 embedding 依赖（server/package.json 只有 seekdb）
    • 
          
  • 文档向量与查询向量都由浏览器内的 Transformers.js 计算
    • 
          
  • 检索排序由 seekdb 的 DBMS_HYBRID_SEARCH 在数据库内完成，前端只发一次请求
    • 
          
  • 不调用任何云端推理 API
